# Change Log

Every amendment to `DESIGN.md` gets a row here, appended at the bottom (chronological
ascending). This file is nothing but the log; the convention it obeys — what a row is, how
a `Ref` slug is assigned, that refs are unique across the whole log, and the pinned form a
citation takes elsewhere in the repo — lives in `DESIGN.md` section 12 and is not repeated
here.

The rows live apart from the design doc for one reason. This table is **append-only**, so
the repo-root `.gitattributes` can mark this file `merge=union`: N task branches that each
append a row then merge without a conflict, instead of the first merging free and every
other one waiting for a person to give the answer that was always going to be *keep both*.
`DESIGN.md` itself must never carry that attribute — its prose is amended in place, and
union merge would silently keep both copies of an amended paragraph rather than conflict.

Rows are appended, never edited and never renumbered. The one failure union merge could
hide — two branches rewriting the *same* row, both copies kept — surfaces as a duplicate
`Ref`, which `scripts/test-changelog.sh` already fails on.
