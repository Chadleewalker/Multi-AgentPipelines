# Documentation Archive

The historical status narrative remains at `docs/STATUS.md` so existing links and change
records stay valid. `docs/change-log.md` remains append-only by design. Both describe how
the system reached its present state; neither is a current configuration source.

Use `docs/control-plane.md` for current operator and agent guidance, the checked-in JSON
contracts for enumerable policy, and `DESIGN.md` for architectural rationale.
